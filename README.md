# GOLD CALCULATOR 360 INFINITY

פלטפורמת מחשבונים אוניברסלית מקצועית – הבית הדיגיטלי למאות מחשבונים מדויקים מכל תחומי החיים.

## סטטוס נוכחי (MVP)

המערכת כוללת כרגע:

- **תשתית מלאה**: Vite + React + TypeScript
- **מנוע חישוב מרכזי** עם דיוק עשרוני, טיפול בשגיאות ונוסחאות
- **רישום מודולרי** של מחשבונים (Calculator Registry)
- **13 מחשבונים פעילים**:
  - מחשבון אחוזים (מתמטיקה)
  - BMI (בריאות)
  - החזר הלוואה / משכנתא (פיננסים)
  - ריבית דריבית (פיננסים)
  - מע"מ (עסקים)
  - טיפ (חיי יום-יום)
  - צבע לקירות
  - עלות דלק
  - הנחה
  - גיל מדויק
  - שטח חדר
  - BMR
  - ריבית פשוטה
- **ממשק Premium** – ערכת נושא כהה/בהירה עם זהב, תמיכה ב-RTL
- **חיפוש בסיסי** + קטגוריות + מועדפים (localStorage)
- **תמיכה רב-לשונית** (עברית + אנגלית מלאים, שלד לשפות נוספות)
- **ניווט ב-Hash** + שמירת מועדפים מקומית

## התקנה והרצה

\`\`\`bash

npm run dev
\`\`\`

\`\`\`bash

\`\`\`

## ארכיטקטורה

\`\`\`
src/
├── calculators/          # כל מחשבון כמודול נפרד
│   ├── math/
│   ├── finance/
│   ├── health/
│   ├── business/
│   └── everyday/
├── engine/
│   ├── precision.ts      # דיוק מספרי + פורמט
│   └── registry.ts       # רישום, חיפוש, קטגוריות
├── components/           # UI
├── i18n/                 # תרגומים
├── types/
└── styles/
\`\`\`

כל מחשבון מייצא \`CalculatorDefinition\` עם:
- שדות קלט
- פונקציית \`calculate\`
- תגיות לחיפוש
- דוגמה
- מחשבונים קשורים

## הוספת מחשבון חדש

1. צור קובץ ב-\`src/calculators/<category>/<id>.ts\`
2. הגדר את האובייקט לפי הטיפוס \`CalculatorDefinition\`
3. קרא ל-\`registerCalculator(...)\`
4. ייבא את הקובץ ב-\`src/calculators/index.ts\`
5. הוסף מפתחות תרגום ב-\`i18n/he.ts\` ו-\`en.ts\`
